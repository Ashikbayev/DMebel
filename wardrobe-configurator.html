Дерево секций (прототип)

Узел: {type:'shelves'|'panels', count, sizes?, children?}. sizes — размеры проёмов в мм (число = фикс, null = авто); нет sizes → поровну. Штанга в ячейку (лист): {type:'rod', drop?, dia?, gap?} — ⚠ допущения без эталона ПО (drop=100 до оси, Ø25, труба=ячейка−2·2). Ящики в ячейку (лист, ВЫВЕРЕНО по эталону ПО): {type:'drawers', count, heights?, boxDepth?(550), topOffset?(50), bottomOffset?(20), clearance?(26), bottomThick?(3), bottomInset?(1), railFront?(70), railBack?(68), fGapTop?(30⚠), fGapBottom?(2⚠), fGapSide?(2)} — свои стойки + 2 планки; на ящик: 2 боковины, перед/зад, дно ХДФ, фасад, направляющие в фурнитуру.

Фасады (накладные створки)

Створки делят фронт по ширине поровну. Открывание чередуется (1-я направо). Раскрой створки = слот − отступы − 2·кромка.
