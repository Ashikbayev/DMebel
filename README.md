# MebelOFF — расчёт мебели и CRM

PWA-приложение для мебельного бизнеса: калькулятор стоимости, коммерческие
предложения, договоры, CRM заказов и конфигуратор шкафов с 3D и раскроем.

Валюта — тенге (₸). Язык — русский. Стек — vanilla JavaScript + HTML + CSS,
без сборщика и зависимостей (Three.js подключается с CDN).

## Архитектура

```
Браузер (PWA, GitHub Pages)
   │  цены (GET/JSONP)          заказы (POST)
   ▼                              ▼
Google Apps Script (Code.gs) ←→ Google Sheets (прайс + лист «Заказы»)
   ▲
   │  статус заказа (без цен)
status.html — личная ссылка клиента
```

Локальные данные (история расчётов, проекты шкафов, ключ CRM) живут
в localStorage браузера; `backup.js` выгружает их в один JSON-файл.

## Файлы

| Файл | Назначение |
|------|-----------|
| `index.html` | Главная страница: вкладки Расчёт / КП / История / Шкаф / Кухня / CRM |
| `main.js` | Калькулятор: загрузка цен, коэффициенты, скидки, КП, договор |
| `crm.js` | CRM: заказы, статусы, оплаты, WhatsApp, аналитика (изолированный модуль) |
| `wardrobe.js` | Конфигуратор шкафа v1 — работает на сайте, заменяется на v2 |
| `wardrobe-core.js` | **Шкаф v2** — ядро геометрии: единый список деталей для 3D/раскроя/чертежа |
| `test-wardrobe-core.js` | Тесты ядра v2 (запуск: `node test-wardrobe-core.js`) |
| `wardrobe-configurator.html` | Автономный тул для проверки ядра v2 |
| `Code.gs` | Google Apps Script: отдаёт прайс, принимает заказы |
| `backup.js` | Экспорт/импорт localStorage (изолированный модуль) |
| `status.html` | Статус заказа для клиента по личной ссылке |
| `styles.css` | Стили основного приложения |
| `manifest.json` | PWA-манифест (установка на телефон) |

## Запуск

Приложение статическое — достаточно открыть `index.html` в браузере или
поднять любой статический сервер:

```bash
npx serve .
# или
python3 -m http.server 8000
```

Цены подтягиваются из Google Sheets через Apps Script; без сети приложение
работает на кэшированных ценах (с предупреждением).

## Тесты

```bash
node test-wardrobe-core.js   # ядро шкафа v2 — должно быть 0 провалов
node --check main.js         # проверка синтаксиса любого файла
```

## Деплой

- Сайт: GitHub Pages из ветки `main`.
- `Code.gs`: вставить в проект Apps Script и создать **новую версию
  развёртывания** (Развернуть → Управление развёртываниями → Новая версия).
  Константа `CRM_TOKEN` в `Code.gs` должна совпадать с ключом, введённым
  на вкладке СРМ (хранится в localStorage, в код не вписывается).

## Процесс разработки

1. Ветка от `main` (`cursor/<задача>`), правки, тесты.
2. Pull Request — просмотр диффа владельцем.
3. Merge в `main` → GitHub Pages обновляется автоматически.

Правила для AI-агентов — в `.cursor/rules/`.

## Шкаф v2 — статус

Ядро (`wardrobe-core.js`): корпус + полки/перегородки + дерево секций
с кастомными проёмами. 125 тестов зелёные. Впереди: штанги, фасады,
ящики, 3D-рендер, UI-редактор. Старый `wardrobe.js` не трогается,
пока v2 не готов к замене.
