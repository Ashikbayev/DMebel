Дерево секций (прототип)

Узел: {type:'shelves'|'panels', count, sizes?, children?}. sizes — размеры проёмов в мм (число = фикс, null = авто); нет sizes → поровну. У shelves флаги bottomShelf?/topShelf? (⚠ ПО СТАНДАРТУ, image 5/7 нет) — граничные полки на низ/под верх ячейки, зона проёмов −16 за флаг. Штанга в ячейку (лист): {type:'rod', drop?, dia?, gap?} — ⚠ допущения без эталона ПО (drop=100 до оси, Ø25, труба=ячейка−2·2). Ящики в ячейку (лист, ВЫВЕРЕНО по эталонам ПО 1 и 2): {type:'drawers', count, mount?('inset'|'overlay'), heights?, boxDepth?(550), topOffset?(50), bottomOffset?(20), clearance?(26), bottomThick?(3), bottomInset?(1), railFront?(70), railBack?(68), fGapTop?(30⚠), fGapBottom?(2⚠), fGapSide?(2), fGapMid?(0.8⚠, overlay), fOverhang?(16, overlay)} — внутренние: свои стойки + 2 планки, фасад в проём секции (утоплен); накладные: без стоек, короб на всю ячейку «как полки», фасад поверх корпуса с перекрытием соседей. Фасад на ячейку (лист, ⚠ ПО СТАНДАРТУ, эталона ПО нет): {type:'facade', count?(1), sizes?, opening?:['left'|'right'], gapTop?(2), gapBottom?(2), gapLeft?(2), gapRight?(2), thick?(16), material?('ldsp')} — створки = проём ячейки − зазоры, перед корпусом, петли накладные по высоте в фурнитуру.

Фасады (накладные створки)

Створки делят фронт по ширине поровну. Открывание чередуется (1-я направо). Раскрой створки = слот − отступы − 2·кромка.

Редактор дерева (клик по ячейке)

Клик по пустой/листовой ячейке — задать тип. Клик по бирке над разделённой ячейкой — изменить деление или убрать его. Изменения сразу пишутся в JSON слева.
